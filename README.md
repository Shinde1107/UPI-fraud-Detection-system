# UPI Fraud Detection System (with Manual Test Cases)

A small machine-learning project that classifies UPI transactions as **Genuine** or **Fraud**, with input validation, data-quality checks and a documented set of functional test cases.

> **Note:** The dataset is synthetic (generated by `generate_data.py`). It contains no real user or bank data.

## What this project covers
- **Data-quality checks:** missing values, duplicate records, invalid amounts and hours (`data_quality.py`)
- **Model:** Random Forest classifier, evaluated with a confusion matrix, precision and recall (`fraud_model.py`)
- **Input validation:** missing fields, wrong data types, zero/negative amount, out-of-range hour, invalid flags
- **Manual functional testing:** 13 test cases covering positive, negative and boundary inputs, with expected vs. actual results (`tests/`)

## Project structure
| File | Purpose |
|---|---|
| `generate_data.py` | Creates the sample dataset `upi_transactions.csv` |
| `data_quality.py` | Checks and cleans the data |
| `fraud_model.py` | Trains the model, validates input, predicts |
| `run_test_cases.py` | Runs the test cases and writes `tests/test_results.csv` |
| `tests/test_cases.csv` | Test scenarios with input and expected result |
| `tests/test_results.csv` | Same cases with actual result and Pass/Fail |
| `tests/defect_log.md` | Template to record defects found |

## How to run
```bash
pip install -r requirements.txt
python generate_data.py      # create dataset
python data_quality.py       # see data-quality report
python fraud_model.py        # train and show confusion matrix, precision, recall
python run_test_cases.py     # execute the test cases
```

## Testing approach
Each test case has an ID, scenario, type (positive / negative / boundary), input, expected result, actual result and status.
Examples: amount = 0, missing field, hour = 25, text in a numeric field, boundary hours 0 and 23.
Any failed case is recorded in `tests/defect_log.md`.

## Tools
Python, Pandas, scikit-learn, manual functional testing
